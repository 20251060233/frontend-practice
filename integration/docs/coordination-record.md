## 结论（已执行）

1. **整合方式**：统一入口 `index.html` + 统一导航/视觉 + 数据同名衔接；三维为独立页 `three-d/scene.html`，首页放置入口卡片，场景页可返回首页。
2. **选型**：图表使用 ECharts 5.6.0（本地 libs），三维使用课堂七的 Three.js 场景（本地 libs），全部离线可用。
3. **数据**：原型使用写死的自习室数组 + `data/data.json`，并提供 `data.empty.json` 做空数据自测；真实接口列入正式版计划。
4. **自查标准**：三档宽度（1280/768/375）整页截图、断网以 file:// 打开取证、Console 以注入采集器显示错误/警告计数、空数据用专用 URL 参数取证。
5. **提交节奏**：骨架 → 交互与图表 → 三维与自查 → 审查修改 → 文档，共 6 次提交，每步可运行、可演示。
