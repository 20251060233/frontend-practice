# 期末大作业实施计划（初稿）

- 作业名称：迷你版校园公共信息与数据展示中心 → 正式版《校园公共信息与数据展示平台》
- 制定日期：2026-09-19
- 制定人：20251060233
- 当前基线：原型已完成（本目录 `integration/`，6 次 Git 提交并推送远程），本计划描述从原型到正式版的实施安排。

## 一、正式版目标（相对原型的增量）

1. 数据层：本地 JSON 升级为可切换的数据源（本地 JSON / 学校公开接口 / 模拟 API），统一数据适配层。
2. 查询：自习室支持楼层、开放状态、入座率区间、关键字组合筛选；保留即时生效与一键重置。
3. 可视化：在柱状图基础上新增入座率趋势折线、开放状态分布饼图；图表与列表联动（来自同伴意见 #6）。
4. 三维：场景内为教学楼/图书馆/钟楼等添加热点标签，点击热点联动展示该楼的自习室与数据（来自轮值结论）。
5. 工程：保持零 CDN 依赖、断网可演示；补齐更多浏览器（Edge/Firefox）自查与第二轮同伴复审。

## 五、验收标准（草案）

1. 四个模块齐备且由统一入口/导航串联，模块间有数据或主题衔接。
2. 断网、空数据、三档宽度、Console 四项自查全部有记录与证据；新增多浏览器抽测。
3. 同伴第二轮审查意见逐条处理并有记录。
4. README 含运行说明与资源来源；Git 提交过程清晰、远程可访问。
5. 现场演示可在无外网环境完成（全部依赖本地化）。
