### 2.2 进度与风险

**整体进度：100%**（全部 6 项任务已完成，3 个页面可正常访问，Console 零报错）

**风险 1：Three.js 与 ECharts 同页渲染冲突**
- 风险描述：首页同时加载 ECharts 折线图和 Three.js 三维场景，两个库都操作 canvas，可能出现渲染冲突或性能问题。
- 应对措施：将三维场景拆分为独立 `three-d/scene.js`，使用 IIFE 隔离作用域；ECharts 与 Three.js 各自初始化独立的 canvas 容器（`#trendChart` 与 `#scene3d`），互不干扰；在 `window.resize` 时分别调用 `chart.resize()` 与 `renderer.setSize()`。

**风险 2：浏览器安全策略拦截本地 JSON（file:// 协议）**
- 风险描述：页面通过 jQuery `$.getJSON` 读取本地 JSON，用户直接双击打开 HTML 时浏览器会拦截请求，导致数据功能全部失效。
- 应对措施：在 `common.js` 的 `loadJSON` 中检测 `window.location.protocol === 'file:'`，主动弹出含原因与解决方法（`python -m http.server` 命令）的红色提示条；README 首页醒目位置注明运行方式。

**风险 3：WebGL 不可用导致页面白屏或崩溃**
- 风险描述：部分老旧浏览器或无显卡环境不支持 WebGL，Three.js 初始化失败可能影响整页。
- 应对措施：`scene.js` 入口处先检测 `THREE` 是否存在及 `webglAvailable()`，不满足时在 `#webglFallback` 容器内显示降级提示文字，不执行任何 Three.js 代码，页面其余功能（图表、搜索）不受影响。

## 三、页面结构、样式与可用性

### 3.1 页面结构说明

**页面清单与导航关系：**

```
index.html（首页） ──┐
                     ├── 共用顶部导航栏（Bootstrap navbar）
dining.html（查询）──┤     ├─ 首页 / 食堂查询 / 数据统计
                     ├── 共用页脚

```

- 三个页面共用同一套导航栏（`dining-navbar`）和页脚（`site-footer`），当前页的 nav-link 添加 `active` 类高亮。

### 4.2 数据处理说明

**JSON 数据组织：**

`data/canteens.json` 结构：
```json
{
  "updateTime": "2026-09-19 08:00",
  "source": "校后勤服务中心（示例数据）",
  "canteens": [ { "id", "name", "campus", "openTime", "floors", "seats", "crowd" } ],
  "dishes": [ { "id", "name", "canteenId", "floor", "stall", "category", "price", "spicy", "rating", "sales" } ]
}
```

`data/stats.json` 结构：
```json
{
  "week": "2026-09-14 至 2026-09-20",
  "source": "校一卡通结算中心（示例数据）",
  "daily": [ { "day", "breakfast", "lunch", "dinner" } ],
  "byCanteen": [ { "name", "value" } ],
  "byCategory": [ { "name", "value" } ]
}
```

**加载与解析流程：**

1. `common.js` 的 `loadJSON(url)` 封装 jQuery `$.ajax`，返回 Promise
2. 各页面 JS 在 `$(function(){...})` 中调用 `loadJSON` 加载对应数据
3. `.then(data => {...})` 中解析数据并渲染 DOM / 初始化 ECharts
4. `.catch()` 中错误提示已由 `loadJSON` 弹出，无需额外处理
5. 查询页支持 `?data=data/dining.empty.json` 切换数据源（空数据自测）

**展示流程：**
- 首页：canteens.json → 统计卡片；stats.json → 折线图
- 查询页：canteens.json → 筛选下拉框 + 菜品卡片；localStorage → 评价列表
- 统计页：stats.json → 柱状图 + 饼图

### 4.3 错误处理说明

**网络失败（JSON 404）：**
- 处理方式：`loadJSON` 的 `.fail` 回调检测 `jqXHR.status === 404`，弹出全局错误条，指出缺失文件路径并提示检查 `data/` 目录
- 截图：`screenshots/rpt-10-network-error.png`（访问 `stats.html?data=data/nonexistent.json`）

**数据为空：**
- 处理方式：检测 `daily.length === 0` 或 `byCanteen.length === 0`，隐藏图表容器，显示琥珀色空数据提示
- 自测地址：`stats.html?data=data/stats.empty.json`
- 截图：`screenshots/rpt-07-empty-data.png`

**非法输入（表单校验）：**
- 处理方式：`validateReview()` 逐项检查菜品必选、昵称非空且≤12字、评分必选、内容非空且≤100字，不通过时在对应字段下方显示红色错误文字
- 截图：`screenshots/rpt-08-form-validation.png`（点击提交按钮后全部字段显示错误）

### 4.4 关键代码说明

**核心功能一：多条件筛选（dining.js）**

```javascript
function getFiltered() {
  var f = getFilters();  // 读取6个筛选条件
  return dishes.filter(function (d) {
    // 关键词：匹配菜名或档口
    if (f.keyword &&
        d.name.toLowerCase().indexOf(f.keyword) === -1 &&
        String(d.stall).toLowerCase().indexOf(f.keyword) === -1) return false;
    // 食堂
    if (f.canteen !== 'all' && d.canteenId !== f.canteen) return false;
    // 类别
    if (f.category !== 'all' && d.category !== f.category) return false;
    // 楼层
    if (f.floor !== 'all' && Number(d.floor) !== Number(f.floor)) return false;
    // 价位（三档区间）
    if (f.price !== 'all' && !matchPrice(d.price, f.price)) return false;
    // 辣度
    if (f.spicy !== 'all' && Number(d.spicy) !== Number(f.spicy)) return false;
    return true;
  });
}
```

**实现思路：** 将所有筛选条件收集到一个对象，用 `Array.filter` 对菜品数组做链式过滤，每个条件不满足即 `return false` 排除。`input` 和 `change` 事件都绑定到 `render()`，实现即时搜索。价位用 `matchPrice` 辅助函数处理区间匹配（`<10`、`10-15`、`>15`）。

**核心功能二：JSON 加载与全局错误处理（common.js）**

```javascript
function loadJSON(url, failedTitle) {
  return new Promise(function (resolve, reject) {
    if (typeof jQuery === 'undefined') {
      showGlobalError('库加载失败', '请确认 libs/jquery-3.7.1.min.js 存在');
      reject({ message: 'jQuery 未加载' });
      return;
    }
    jQuery.ajax({ url: url, dataType: 'json', cache: false })
      .done(function (data) { resolve(data); })
      .fail(function (jqXHR, textStatus, err) {
        var detail;
        if (window.location.protocol === 'file:') {
          detail = '原因：file:// 直接打开被拦截\n解决：python -m http.server 8787';
        } else if (jqXHR.status === 404) {
          detail = '原因：数据文件未找到（404）：' + url;
        } else {
          detail = '原因：' + (err || textStatus) + '（状态码：' + jqXHR.status + '）';
        }
        showGlobalError(failedTitle || '数据加载失败', detail);
        reject({ message: detail, status: jqXHR.status });
      });
  });
}
```

**实现思路：** 封装为 Promise，统一处理三类失败场景：jQuery 库缺失、file:// 协议拦截、HTTP 404/其他错误。每种情况给出针对性的原因说明和解决方法。`common.js` 不依赖 jQuery，确保即使 jQuery 加载失败也能弹出错误提示。

### 5.2 数据来源与正确性

- 所有图表数据来自 `data/stats.json`，`source` 字段标注「校一卡通结算中心（示例数据，仅用于课程作业演示）」。
- 折线图数据核验：`daily` 数组共 7 条（周一至周日），每条含 breakfast/lunch/dinner 三个值，与图表三条曲线一一对应。
- 柱状图数据核验：`byCanteen` 共 4 条（紫荆/桃李/清芬/丁香），数值分别为 21650/18920/12480/8640，与柱顶标签一致。
- 饼图数据核验：`byCategory` 共 5 类，米饭套餐38、面食24、麻辣烫15、粥粉简餐13、甜点饮品10，总计100道，饼图各扇区百分比与数值比例一致。

### 5.3 选型说明

**选择 ECharts 的原因：**
1. 中文文档完善，API 友好，适合课程作业快速上手
2. 支持折线、柱状、饼图等多种类型，一套库满足全部图表需求
3. 内置 tooltip、legend、resize 响应式等功能，无需额外插件
4. 可下载单文件 `echarts.min.js` 离线使用，不依赖 CDN

**图表类型选择理由：**
- **折线图**：展示一周三餐人次随时间的变化趋势，适合表现时序数据波动
- **柱状图**：对比四个食堂的就餐人次总量，柱状图直观展示数值差异
- **饼图**：展示菜品类别占比，适合表现部分与整体的比例关系

## 六、三维展示与主题关联

### 6.1 三维场景截图

截图：`screenshots/06-3d-scene.png`（也可见 `rpt-06-index-full.png` 底部）

场景构成：餐厅地板 + 后墙三个档口（面食/套餐/风味，含柜台、招牌、菜盆）+ 6 张圆桌及配套圆凳 + 各档口前排队的人形 + 3 盏吊灯。

### 6.2 主题关联说明

作品主题为「校园食堂」，三维展示还原了一层餐厅的真实布局：
- **档口**对应 JSON 数据中的食堂窗口（面食/套餐/风味三大类）
- **圆桌座椅**对应食堂就餐区
- **排队人流**对应就餐高峰期的排队场景

三维展示让用户直观了解食堂空间布局，与菜品查询（二维）和数据统计（图表）形成互补，从「空间—信息—数据」三个维度呈现校园食堂主题。

### 6.3 交互说明

基于 Three.js 的 `OrbitControls`：
- **旋转**：鼠标左键拖拽，360° 环绕查看场景
- **缩放**：鼠标滚轮，拉近或拉远视角（minDistance: 6, maxDistance: 40）
- **平移**：鼠标右键拖拽，平移观察点
- **阻尼效果**：`enableDamping = true`，旋转有惯性，体验更自然
- **动画**：排队人形上下起伏（模拟排队移动），招牌灯呼吸式发光
